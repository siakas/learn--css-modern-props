あなたはドキュメントの管理者です。本プロジェクトのドキュメント群（`README.md`、`CLAUDE.md`、`AGENTS.md`）を最新のリポジトリ状況に基づいて更新してください。

## 各ドキュメントの役割

| ドキュメント | 対象読者                      | 役割                                               | 更新頻度               |
| ------------ | ----------------------------- | -------------------------------------------------- | ---------------------- |
| `README.md`  | 人間（GitHub 訪問者、開発者） | プロジェクト紹介、セットアップ、学習コンテンツ一覧 | 演習追加・変更のたびに |
| `CLAUDE.md`  | Claude Code                   | 技術スタック、コーディング規約、ページ実装パターン | 規約変更時のみ         |
| `AGENTS.md`  | AI エージェント全般           | 設計方針、スキル案内                               | 方針変更時のみ         |

**重要:** `CLAUDE.md` と `AGENTS.md` は規約のドキュメントです。リポジトリ全体の方針が大きく変わらない限り変更を加えないでください。

## 実行手順

### Step 1: リポジトリの現状を収集

以下のファイルを読み取り、最新の情報を収集してください。

1. **学習コンテンツの定義**
   - `consts/experiments.ts` — experiments の一覧（タイトル、説明、パス）
   - `consts/foundations.ts` — foundations の一覧（タイトル、説明、パス）

2. **カスタムフック**
   - `app/(with-sidebar)/experiments/**/hooks/*.ts` — カスタムフックのファイル一覧
   - `app/(with-sidebar)/experiments/**/hooks/*.test.ts` — テストファイルの有無

3. **技術スタック**
   - `package.json` — 主要パッケージのバージョン（next, react, typescript, tailwindcss, zustand, @biomejs/biome, vitest）

4. **Claude Code スキル**
   - `.claude/skills/*/SKILL.md` — 登録されているスキルの一覧

5. **プロジェクト構造**
   - `app/(with-sidebar)/` 配下のディレクトリ構成

### Step 2: README.md を更新

収集した情報に基づき、以下のセクションを更新してください。

#### 2-1. 技術スタック

`package.json` のバージョンと README.md の記載を比較し、メジャーバージョンが変わっている場合は更新する。

#### 2-2. 学習コンテンツ（Experiments / Foundations テーブル）

`consts/experiments.ts` と `consts/foundations.ts` の内容を正とし、テーブルを再生成する。

- 順序は `consts/` ファイルの定義順に従う
- タイトルと概要は `consts/` の `title` と `description` をそのまま使用する

#### 2-3. プロジェクト構造

experiments と foundations の数が正確か確認し、必要に応じて更新する。

#### 2-4. カスタムフックとテスト

カスタムフックの一覧テーブルを現状と照合する。

- 新しいフック（テスト付き）が追加されていれば追加する
- 削除されたフックがあれば削除する
- テストの有無（✅ / —）を正確に反映する

#### 2-5. Claude Code スキル

`.claude/skills/` 配下のスキル一覧を確認し、追加・削除があれば更新する。

### Step 3: CLAUDE.md / AGENTS.md の差分チェック

以下の観点で現状との乖離がないか確認し、**変更が必要な場合のみ**報告してください。変更が不要な場合は「変更不要」と報告するだけで構いません。

#### CLAUDE.md のチェック項目

- [ ] 技術スタックのメジャーバージョンが `package.json` と一致しているか
- [ ] ディレクトリ構造の記載が実際の構成と一致しているか
- [ ] ページ実装パターン（`PageContent`, `LearningTips` 等）が現行のコードと一致しているか
- [ ] Biome 設定のポイントが `biome.json` の内容と一致しているか
- [ ] コマンド一覧が `package.json` の `scripts` と一致しているか

#### AGENTS.md のチェック項目

- [ ] 設計方針が現在のプロジェクトの実態と整合しているか
- [ ] Claude Code スキルの一覧が `.claude/skills/` の内容と一致しているか
- [ ] スキルの説明（目的、自動起動条件、制約等）が各 SKILL.md の内容と整合しているか

```
- [変更が必要な項目の箇条書き、または「変更不要」]
```
