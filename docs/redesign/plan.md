# サイトリニューアル計画書

モダン CSS 学習サイトのデザインを、既存のスタイルにとらわれることなく、モダンなデザインで全面リニューアルします。
コンテンツ（テキスト・コードサンプル・デモ）はそのままに、見た目と体験を刷新します。

---

## 現状の確認

- **フレームワーク**: Astro + React + Tailwind CSS v4 + shadcn/ui
- **ページ構成**: ホームページ（カード一覧） + 11 記事ページ
- **現在のレイアウト**: 左サイドバー（ナビ）＋ 右メインコンテンツの 2 カラム
- **現在の配色**: 白背景・ティール（#319795）アクセント
- **変更対象**: レイアウト・スタイル全般（記事内 CSS デモ用の `<style>` タグは除く）

---

## 備考

- 各記事ページ内の `<style>` タグ（CSS デモ用スタイル）は変更しません
- コンテンツ（テキスト・コード・デモ HTML）は変更しません
- shadcn/ui コンポーネント（Button、Card）は引き続き利用可能です
